# SVU_BWP501_F25_HW
وقع تفاعلي متكامل للجامعة الافتراضية، صُمم كمنصة رقمية موحدة تهدف إلى تسليط الضوء على الحياة الأكاديمية والأنشطة الموازية. يركز الموقع بشكل أساسي على عرض وإدارة فعاليات الجامعة، المؤتمرات، والورش التدريبية، مما يتيح للطلاب والمتابعين البقاء على اطلاع دائم بكل ما هو جديد ومتابعة الأنشطة الجامعية المتنوعة وسير أحداثها بسهولة وسلاسة.
